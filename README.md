## Preview the full Portfolio locally

Open the parent `MongoScripts` folder in VS Code. In **Run and Debug**, select **Portfolio homepage (VS Code browser tab)** and press **F5**. VS Code starts the full local Portfolio plus the Web App API/client, then opens the homepage in an editor browser tab. Clicking **Open Portal** opens the live Web App source and talks to the local API, using PostgreSQL configured for `testforge-src/server`. The preview does not serve the separate desktop app or any `.env` files. Keep the debug session running while you use the page.
